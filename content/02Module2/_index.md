### Introduction 
In order to begin exploring what FortiCNAPP has to offer, we need to perform some integrations with cloud environments. In this module, we'll look at the supported clouds, workload types, container repositories, and identity providers. We will cover Code Security onboarding in a later module. 

**NOTE:** There are many nuances to the respective integration points, but we will avoid unnecessary documentation overload. This course is not a documentation repository. Rather, we will rely on official documentation where necessary and focus on streamlining the onbaording process so you can get to using the product as quickly as possible. We will cover the following topics in each chapter of this module:

1. Cloud Configuration and Audit Log integration
2. Agent based integration
3. Agentless workload scanning integration
4. Container Repository integration
5. Identity Provider integration
